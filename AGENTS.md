- Before changing Rust, Lua/Neovim integration, build configuration, tests,
  workflows, dependencies, compatibility or usage documentation, release
  tooling, or version metadata, read
  `.agents/skills/maintain-cargo-nvim/SKILL.md`. It is the authoritative source
  for project-specific invariants and validation.

- Obey higher-level shell-wrapper, safety, and publishing instructions.
